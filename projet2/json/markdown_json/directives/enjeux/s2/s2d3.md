# s2d3

Source : `directives/enjeux/s2/s2d3.json`

## Contenu

- **directive** :
  - **id** : 2-3
  - **title** : Solidarité migratoire européenne
  - **description** : Quotas contraignants de répartition des migrants. Instaurer un mécanisme permanent de répartition équitable des demandeurs d’asile et de protection internationale entre États membres.
  - **commission** :
    - **role** : Porte la proposition initiale, garantit la cohérence institutionnelle et fait le lien entre Parlement, Conseil et acteurs externes.
    - **enjeux** :
      - Assurer une répartition équitable des demandeurs d’asile dans un cadre contraignant.
      - Équilibrer solidarité européenne, pressions sociales nationales et respect des droits humains.
      - Anticiper les blocages politiques et favoriser les compromis viables entre États membres.
  - **countries** :
    - **Élément 1** :
      - **name** : France
      - **role** : Non-porteur
      - **position** : Soutient une solidarité migratoire sous conditions de contrôle renforcé.
      - **enjeux** :
        - Équilibre entre humanité et sécurité.
        - Préserver la cohésion sociale nationale.
      - **role\_description** : Médiateur entre les pays favorables aux quotas et les pays réticents.
    - **Élément 2** :
      - **name** : Allemagne
      - **role** : Non-porteur
      - **position** : Soutien affirmé à une répartition contraignante et ambitieuse.
      - **enjeux** :
        - Répondre à la pression migratoire interne.
        - Consolider son rôle moteur en Europe.
      - **role\_description** : Moteur des alliances progressistes en faveur d’une solidarité accrue.
    - **Élément 3** :
      - **name** : Italie
      - **role** : Porteur
      - **amendment** : Soutenir prioritairement les centres d’accueil aux frontières extérieures.
      - **enjeux** :
        - Alléger la pression migratoire sur ses frontières.
        - Obtenir un soutien financier et logistique accru.
      - **strategie** : Mettre en avant la solidarité concrète avec les pays en première ligne.
    - **Élément 4** :
      - **name** : Hongrie
      - **role** : Porteur
      - **amendment** : Limiter les quotas de répartition à 80% de la capacité nationale.
      - **enjeux** :
        - Préserver sa souveraineté nationale.
        - Limiter l’impact social et politique d’une répartition contraignante.
      - **strategie** : Fédérer les pays hostiles à une approche obligatoire.
    - **Élément 5** :
      - **name** : Pologne
      - **role** : Porteur
      - **amendment** : Reporter l’application de la directive de deux ans.
      - **enjeux** :
        - Limiter les obligations immédiates.
        - Obtenir flexibilité et temps d’adaptation.
      - **strategie** : Former un front commun avec d’autres pays réticents (Hongrie, Suède).
    - **Élément 6** :
      - **name** : Suède
      - **role** : Porteur
      - **amendment** : Exclure certains États membres des obligations de répartition.
      - **enjeux** :
        - Limiter la portée des quotas contraignants.
        - Protéger son autonomie nationale.
      - **strategie** : Obtenir des exemptions ciblées pour certains États.
  - **parties** :
    - **Élément 1** :
      - **name** : Parti Populaire Européen
      - **role** : Non-porteur
      - **position** : Soutient une solidarité limitée, conciliant répartition et subsidiarité.
      - **enjeux** :
        - Maintenir l’équilibre entre unité européenne et souveraineté nationale.
      - **strategie** : Proposer des compromis modérés pour rallier les deux camps.
    - **Élément 2** :
      - **name** : Socialistes et Démocrates
      - **role** : Porteur
      - **amendment** : Instaurer un fonds européen pour l’intégration des migrants.
      - **enjeux** :
        - Promouvoir justice sociale et intégration.
        - Renforcer la cohésion territoriale.
      - **strategie** : Construire des alliances avec Renew et les Verts pour renforcer l’aspect social.
    - **Élément 3** :
      - **name** : Renouveau Européen
      - **role** : Porteur
      - **amendment** : Augmenter les quotas de répartition de 20%.
      - **enjeux** :
        - Donner une réponse ambitieuse et pragmatique.
        - Allier solidarité européenne et efficacité.
      - **strategie** : Occuper une position de trait d’union entre progressistes et modérés.
    - **Élément 4** :
      - **name** : Verts/ALE
      - **role** : Non-porteur

      - **strategie** : Faire pression pour aller plus loin que la proposition initiale.
    - **Élément 5** :
      - **name** : Conservateurs et Réformistes

      - **enjeux** :

    - **Élément 6** :
      - **name** : Gauche Unitaire
      - **role** : Porteur

      - **enjeux** :
        - Renforcer la justice sociale et le respect des droits.
        - Soutenir les États en première ligne de l’accueil.
      - **strategie** : Faire pression pour plus d’équité et de solidarité.
