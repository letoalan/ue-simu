# indicators

Source : `finance/shared/indicators.json`

## Contenu

- **envelope** :
  - **nom** : Enveloppe globale du fonds
  - **unite** : Mds €
  - **description** : Volume total de mutualisation sur la période décennale
- **contribution** :
  - **nom** : Contribution nationale
  - **unite** : Mds €
  - **description** : Versement de l'État membre au budget commun
- **allocation** :
  - **nom** : Allocation reçue
  - **unite** : Mds €
  - **description** : Dotation perçue par l'État membre pour ses projets
- **net\_balance** :
  - **nom** : Solde financier net
  - **unite** : Mds €
  - **description** : Différence entre allocation reçue et contribution versée
- **cofinancing\_rate** :
  - **nom** : Taux de cofinancement
  - **unite** : %
  - **description** : Part des projets financée par le budget national
- **coverage\_rate** :
  - **nom** : Taux de couverture du besoin
  - **unite** : %
  - **description** : Part du besoin restant couverte par l'UE et le cofinancement
